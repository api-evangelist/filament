# Filament Docs

> Filament (Filament Finance) is a hybrid on-chain perpetual / derivatives DEX on the Sei Network, pairing an off-chain orderbook with a Compartment-Based (COMB) liquidity pool for deep liquidity in thin markets. Filament Pro offers up to 30x leverage on crypto perpetuals with USDC collateral, and exposes a signature-authenticated REST + WebSocket order-book API for market makers.
